# Exercise V2 data and media sources

## Structured exercise metadata used

- Source: [yuhonas/free-exercise-db](https://github.com/yuhonas/free-exercise-db)
- Pinned revision: `b0eed061e1c832b3ed815fbaa4b45b3cdc14df49`
- License: Unlicense/public-domain dedication as declared by the repository
- Use: normalized exercise names, instructions, categories, difficulty, force, mechanic, equipment, and muscle metadata
- Import: `backend/scripts/seed_exercises.py`
- Accessed: 2026-08-18

The seed importer intentionally does not import the source image paths. The repository describes the dataset as public domain, but image provenance is not separately confirmed in the repository issue history. GymAI therefore treats the metadata and media rights separately and does not ship those images.

## Media sources evaluated but not integrated

- [RepDB](https://repdb.co/): its free tier advertises commercial in-app use with attribution, but the preview assets are CC BY-NC 4.0 and the production animation bundle is part of a paid tier. No RepDB media is included until the appropriate license is acquired.
- [ExerciseDB API](https://exercisedb.io/terms): the API terms describe limited-use access for GIF visuals and restrict independent redistribution. It is not integrated.
- [free-exercise-db-with-videos](https://github.com/arhxam/free-exercise-db-with-videos): the repository code is presented as MIT, but the provenance and commercial rights of the individual demo videos were not independently verified. It is not integrated.

## GymAI media architecture

Exercise media is stored in `exercise_media` with rendered animation/video, poster, camera, version, status, license, attribution, dimensions, and duration metadata. Media is generated by the local Blender pipeline documented in `docs/exercise-animation-system.md` and registered with `backend/scripts/register_generated_media.py`. The unlicensed sample GIFs are not shipped. Wikimedia Commons was researched as a legally reusable alternative, but no remote third-party media is bundled until its exact rights and operational hosting are approved.
