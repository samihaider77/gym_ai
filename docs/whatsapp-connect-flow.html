Small addition: one tap on Send

Scanning only opens the chat with LINK 482913 typed. The member taps Send once. That message is how we learn their number safely, without them typing it.

Reminders cost a little

When members ask, the reply is free (1,000 a month per number). When the bot messages first, as a reminder does, Meta charges about $0.015 per message. So start with "ask anytime" and add reminders as a gym feature.

Where your number is used

One bot number, shared by every member

  • You need one extra SIM, used once to receive Meta's code. It shouldn't already be on WhatsApp. After that it can sit in a drawer.
  • Members never see each other. Each chat with the bot is private, like each customer chatting with a shop's number.
  • The name "LiftAndPlate" and the logo appear once Meta approves the display name. Before that the chat shows the number.
  • For gyms later: each gym can have its own number and name (e.g. "PowerHouse Gym Coach"), running on the same backend.
